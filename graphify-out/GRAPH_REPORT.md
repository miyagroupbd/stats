## Architecture notes (graph sweep 2026-08-04)

**What it is:** stats.miyagroupbd.com operations board — FastAPI backend + Next.js (App Router) frontend over the shared email-pipeline PostgreSQL. First graph report for this project.

- **`backend/app/core/`** — `config.py` Settings (CORS list), `db.py` connect/disconnect lifecycle, `security.py` JWT (create/decode access token), bcrypt password hashing, and the SAME Fernet encrypt/decrypt as email-pipeline `db/crypto.py` (APP_SECRET must match or SMTP passwords won't decrypt).
- **`backend/app/routers/`** — `auth` (login/me), `domains` (CRUD, admin-gated), `campaigns` (CRUD), `leads` (CRUD + CSV `import_leads` + per-lead messages), `messages` (list/detail + approve/reject/send — the message-approval workflow), `runs` (`trigger_run` writes queued Run → email-pipeline worker executes; list/detail + `get_run_logs` + `stream_run_logs` live streaming), `stats` (domain stats, reply/bounce rates), `automations` (n8n summary/workflows/executions via `integrations/n8n.py`, key-gated, degrades gracefully).
- **`backend/app/services/runner.py`** — `start_run` is the ONLY pipeline trigger; no agent code imported (decoupled by design).
- **`backend/app/schemas/`** — pydantic in/out models per resource; `deps.py` `get_current_user` / `require_admin`.
- **`frontend/src/app/(dashboard)/`** — pages: overview (StatCards), domains + `[slug]` detail (SMTP config, send-window day toggles, run/delete), leads (CSV import), messages (approval queue w/ keyboard nav), runs + `[id]` live log viewer (poll + ingest), campaigns, automations, settings, plus `login`.
- **`frontend/src/lib/`** — `api.ts` token-injecting `apiFetch` + ApiError, `auth.tsx` AuthProvider/useAuth, `hooks.ts` useDomains, `toast.ts` confirmToast.

**Gotcha (from workspace CLAUDE.md, still true):** `stats/db/` mirrors the email-pipeline schema; email-pipeline owns alembic. Keep in sync on schema changes.
